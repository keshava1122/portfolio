An innovative AI system that converts spoken user input into professionally formatted resumes and cover letters. I engineered a robust preprocessing layer capable of noise removal and multilingual translation. Using a hybrid extraction approach, the system combines strict regex anchors with LLM-based role inference (Gemini/Mistral) to intelligently auto-translate and structure raw speech into perfect resume templates via n8n automation.
